# 轻课 Android 0.4.1

Android 8.0 及以上可安装的开发体验版。

## 本次修复

- 修正学校登录跳转的误拦截规则。
- 保留登录弹窗的真实窗口、表单 POST 和回调。
- 学校 HTTP GET 旧地址改用 HTTPS，仍校验证书。
- 新增不含账号、密码、验证码、Cookie 或网址参数的登录排查信息。

## 安装

下载 `qingke-0.4.1-debug.apk`，发到安卓手机后使用系统安装器打开。与此前本聊天提供的版本签名一致，支持覆盖升级，更新前建议导出备份。

首次使用：导入昆工课表 → 在学校网页自行登录 → 课表入口 → 提取课表 → 核对后保存。

若登录仍卡住，点击学校窗口顶部提示，选择「复制排查信息」。请勿提交账号密码、验证码、Cookie 或带票据的完整网址。

## 验证与边界

- 24 项 JavaScript 测试、40 项导航断言和 27 项课表/提醒断言通过。
- APK v2/v3 签名验证通过，证书与此前体验版一致。
- 学校完整登录、通知送达、小组件与不同机型兼容性尚未通过真机验证。
- 本安装包使用开发签名。仓库及 CI 不包含该私钥；CI 自动生成的 APK 签名可能不同，安装请选择这里的 Release 附件。

附带 `SHA256SUMS.txt` 可校验文件完整性。
