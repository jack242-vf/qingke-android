# 轻课 Android 体验版 0.4.1

独立实现的课表应用，使用原生 Android 容器与内置网页界面，不依赖 Sites 网站运行，不包含 WakeUp 的品牌、代码或素材。

## 已实现

- 离线课表、课程编辑、单双周、导入时保留不连续周次与按周更换教室。
- 最多 10 份独立课表，切换与改名，浅色/深色主题。
- 每日课程卡片与整周课表切换，完整显示长课程名称、教室、教师、时间和进行状态。
- 导入时可新建课表保存，保留当前数据；存储失败会撤销未完成的新建。
- 原生学校登录页：自行登录昆工 → 点击课表入口 → 提取 → 回到轻课预览确认。
- 昆工 13 节作息、多教师共同授课合并、课程冲突与未知格式提示。
- Android 系统文件选择器导入 JSON；系统保存文件界面导出备份。
- 课程详情卡片、备注、一门课多个时段、手动选择不连续周次。
- 选定周的单次调课、停课，保持其他周的安排；多时段保存前统一检查冲突。
- 快速周次滑杆和周次按钮、左右滑动切周、非本周状态和一键返回本周。
- 各课表独立保存字体大小、周视图高度、周末显示、主题与视图。
- 今日课表桌面小组件，随当前课表更新，支持调整大小和手动刷新。
- 上课提醒（默认关闭）、提前 5/10/15/30 分钟、测试通知、通知与准时提醒权限设置。
- 切换课表、导入、编辑、单次调课后同步更新后台本地副本；重启、更新应用、修改时间后重新安排提醒。
- 适用于 Android 8.0（API 26）及以上，建议使用最新 Android System WebView。

## 安装与使用

将 `output/qingke-0.4.1-debug.apk` 发到安卓手机，用系统安装器打开并按提示允许该文件来源的安装。这是开发签名的体验版，没有上架应用商店。此处生成的 0.4.1 与前一版应用 ID 和签名保持一致，可覆盖更新；更新前仍建议导出备份。

进入 App 后：

1. 点击「导入昆工课表」，在学校页面自行完成登录和验证码。
2. 若登录后到门户，点击顶部「课表入口」。在课表页面选择学期。
3. 点击一次「提取课表」，会自动打开并等待「全部课程」，读到完整列表后返回轻课。等待约 30 秒后会提示超时，避免无限加载；页面加载完成后可以重试。
4. 返回轻课后核对卡片预览、学期周数和第一周星期一。可选新建课表保存（有原课表时默认选中），或者替换当前课表，再勾选确认导入。若没有自动带出起始日期，以学校课表显示的起始日期填写。

也可以使用「文件 / 文本导入」作为学校网页兼容问题的备用方案。网页版本与 APK 数据互相独立，可在网页中导出备份，再在 APK 中导入。每份课表分别导出，切换到对应课表后再导入。

数据保存在应用内部。卸载或清除应用数据会丢失课表，请先导出备份。学校登录会话通过 Android WebView Cookie 机制保留，不读取或导出密码、Cookie、成绩和个人资料。应用无统计或第三方数据上传。

## 课程管理与外观

点击课程先查看详情，再点「编辑整门课」。每个时段可单独选星期、节次、老师、教室和周次；用「添加时段」或「复制此时段」录入每周不同安排。至少选择一周，每门课程最多 30 个时段；冲突时不会部分保存。导入的新课程按课程名称建立分组，旧版已存的未分组时段保持原样。

在详情中点击「调整第 N 周」可移动该周的一次课；点击「第 N 周停课」仅取消该次课。恢复停课可在原时段的周次选择中重新勾选；若原时段仅有这一周、已被移除，则需重新添加时段。删除可选择只删当前时段或整门课程。

点主界面的周次按钮可以拖动滑杆或点周次按钮跳转；每日/整周课表区域支持横向滑动切换周次。点「课表外观」可调整当前课表的大字、网格高度和周末显示。关闭周末只改变周视图，周末课程仍在每日列表中。

0.3.0 会读取旧版 version=1 备份，编辑后保存为 version=2，以明确保留不连续周次。新备份请使用 0.3.0 或后续版本恢复，旧版轻课不支持 version=2。仅更新 APK 不会清空原课表。

功能参考 [WakeUp 官方主界面指南](https://www.wakeup.fun/doc/main_interface.html)与[课程编辑指南](https://www.wakeup.fun/doc/add_course.html)，界面和代码均为独立实现，未打包参考产品的图片或资源。

## 提醒与桌面小组件

点击底部「提醒与桌面」。开启提醒、选择提前时间并保存；Android 13 及以上需要允许通知。可点击「发送测试通知」检查通知栏是否正常。测试通知不会打开正式提醒开关。

Android 12 及以上可通过「允许准时提醒」进入系统的闹钟与提醒权限页。未授权时使用标准提醒，可能延迟。权限页返回 App 后会重新安排提醒；不要把本功能当作保证准时的闹钟。此处理遵循 [Android 官方闹钟文档](https://developer.android.com/develop/background-work/services/alarms)。

提醒只使用当前选中的课表，支持单双周和不连续周次。每次只安排最近一条系统闹钟，触发后安排下一条，并记录已提醒课程避免重复。已结束的课和迟到超过 30 分钟的提醒不补发。切换到空课表、关闭通知或关闭提醒后取消已安排提醒。若后台副本同步失败，会清除旧副本并暂停提醒，避免继续提醒过期课程。

桌面小组件：点击「添加今日课表到桌面」，或者长按手机桌面空白处 → 小组件 → 轻课。小组件随当前课表变化，按大小显示 1–4 次今天尚未结束的课程。点小组件打开 App，点「刷新」立即更新。系统约每 30 分钟请求一次刷新，可能因省电而延后，不是逐分钟实时刷新。它只在主屏幕显示，不是锁屏小组件。

提醒设置对当前选中课表生效，切换课表会重排；提醒开关与系统权限不包含在课表 JSON 备份中，换设备后需重新开启。用于提醒和桌面的课程副本存放在应用私有存储，仅包括当前课表的必要课程字段，不包含备注、学校密码或登录 Cookie。以手机本地日期、时区和时间计算。

应用声明通知、准时提醒和开机恢复权限，在用户开启相关功能时再发起必要系统授权。强行停止 App、厂商后台限制、勿扰模式或通知渠道关闭都可能影响送达。重启、应用更新和时间变化会尝试重排，重新打开 App 也会检查恢复。

## 0.4.1 登录兼容修复

本版针对手机反馈的「已阻止非学校 HTTPS 地址」排查并修正兼容问题：

- 主页面按网址来源判断，避免严格解析完整查询/SPA 片段导致合法学校域名被误判。
- 已在学校页面内的空白页和脚本导航可以正常继续；验证码/单点登录子页面不再覆盖主页面状态。
- 学校的 HTTP 旧链接只在主页面 GET 跳转时自动改用同一学校域的 HTTPS，不重新发送 POST，不放开明文网络或证书错误。
- 登录新窗口保留为真实 WebView 子窗口，保留表单 POST 和 window.opener 回调，不再把首个网址强行转为新 GET 后销毁窗口。
- 初始打开统一认证入口。登录后点「课表入口」再提取课程。

点击学校窗口顶部提示可打开「登录帮助」并复制排查信息，仅包含 App/Android/WebView 版本、当前与最近异常的来源域名及错误类型，不记录路径、查询参数、账号、密码、验证码或 Cookie。截图本身没有显示被拦截的网址，尚无法确认实际手机触发的具体分支，仍需覆盖安装后验证登录完整流程。学校域名以外的主页面依旧拦截。

## 当前边界与验证

已完成 APK 构建和 v2/v3 签名校验；Java 导航限制与登录兼容 40 项断言通过，当前 24 项 JS 测试覆盖提取、日期匹配、等待时防重复导航、每日筛选和状态、创建独立课表与存储失败撤销。浏览器预览验证了每日/整周切换、多时段与不连续周次保存、周次快速选择、单周调课与其他周保持原样、详情备注、独立外观和导入新课表。另有 27 项纯 Java 断言覆盖周次边界、单双周、不连续周次、提醒提前量、重复过滤、过期过滤和空课表。左右滑动手势仍需在实际 Android WebView 中验证。网页基础课表解析另外沿用轻课已验证的逻辑。

尚未通过安卓真机或模拟器测试。学校 SSO、多窗口跳转、验证码和文件选择器需要在手机上实际验证，不能保证首版兼容所有机型。提醒送达、系统授权与桌面小组件未通过真机或模拟器验证。云同步尚未实现。此体验版不等于 WakeUp 的完整功能。

## 源码与构建

仓库包含 Gradle Wrapper。环境配置、标准构建、Windows 最小构建与签名说明见 [构建说明](BUILD.md)。

原生层不向学校网页暴露 JavaScript 接口；学校网络主页面限制为学校域 HTTPS；HTTP 旧链接先升级，内部空白页和脚本导航按来源判断，不忽略 TLS 证书错误。App 页面使用独立本地 HTTPS 来源，禁止远程脚本和网络请求；原生操作只接受内置页面的请求。学校课程只在用户点击提取后读取。
